# Стиль кода

Настройки синхронизированы со `stingray_core`.

## Основные правила C++

- отступ — 4 пробела;
- максимальная длина строки — 100 символов;
- табуляция не используется;
- фигурные скобки оформляются в стиле Allman;
- указатель и ссылка примыкают к типу;
- функции и методы используют `snake_case`;
- константы и значения `enum` используют `UPPER_CASE`.

Полные правила находятся в `.clang-format` и `.clang-tidy` в корне репозитория.

## VS Code

Для корректной навигации и диагностики откройте проект внутри подготовленного
контейнера:

1. Установите расширение `Dev Containers` от Microsoft.
2. Откройте репозиторий в VS Code.
3. Выполните `Dev Containers: Reopen in Container` через `Ctrl+Shift+P`.

Контейнер собирается из основного `docker/Dockerfile`. После создания CMake
автоматически формирует базу компиляции в `/tmp/umas-gui-build`, где `clangd`
видит заголовки ROS 2, Qt, GStreamer и остальные зависимости проекта.

При открытии репозитория VS Code предложит установить рекомендованное расширение
`clangd` от LLVM. Настройки в `.vscode/settings.json` включают:

- автоматическое сохранение через одну секунду после изменения;
- форматирование всего файла C или C++ при `Ctrl+S` и автоматическом сохранении;
- использование корневого `.clang-format`;
- фоновую индексацию и проверки из `.clang-tidy`;
- чтение базы компиляции из `build/compile_commands.json`.

Встроенные IntelliSense и formatter расширения Microsoft C/C++ отключены, чтобы два
language server не конфликтовали. В Dev Container программа `clangd` и все необходимые
заголовки уже установлены. Путь к исполняемому файлу специально не закреплён, чтобы
настройка работала на разных компьютерах. Команда `Format Document` также использует
правила проекта.

## Проверка форматирования

```bash
./scripts/ci/format.sh
```

Скрипт проверяет файлы C и C++ внутри `src/`, не изменяя их.

Чтобы применить форматирование:

```bash
find src -type f \( -name '*.cpp' -o -name '*.hpp' -o -name '*.c' -o -name '*.h' \) \
    -print0 | xargs -0 clang-format -i
```

Массовое форматирование существующего кода следует выполнять отдельным коммитом.

## clang-tidy

Для анализа требуется база компиляции:

```bash
cmake -S . -B build -DCMAKE_EXPORT_COMPILE_COMMANDS=ON
clang-tidy -p build src/path/to/file.cpp
```
