# Сборка и запуск

## Первый запуск на новом компьютере

Установите Docker, клонируйте репозиторий и выполните из его корня:

```bash
./scripts/install-cli.sh
umas-gui docker-build
umas-gui build
./scripts/install-desktop-shortcut.sh
```

Первые три команды устанавливают локальную CLI-команду, собирают Docker-образ и
приложение. Последняя команда создаёт на рабочем столе ярлык `UMAS GUI` с логотипом
Гидронавтики. Ярлык запускает приложение через `umas-gui run`.

Если `umas-gui` не находится после установки, добавьте локальный каталог программ
в `PATH` и перезапустите терминал:

```bash
export PATH="$HOME/.local/bin:$PATH"
```

## Команда `umas-gui`

Доступные команды:

```bash
umas-gui docker-build  # собрать или обновить Docker-образ
umas-gui build         # собрать только приложение
umas-gui run           # запустить пульт
umas-gui shell         # открыть shell в контейнере
umas-gui format        # применить clang-format
umas-gui check         # проверить форматирование
```

При первом запуске или после изменения `docker/Dockerfile` выполните
`umas-gui docker-build`. В повседневной разработке достаточно быстрой команды
`umas-gui build`: существующий Docker-образ при этом не пересобирается.

## Ярлык на рабочем столе

Установить или обновить ярлык можно командой:

```bash
./scripts/install-desktop-shortcut.sh
```

Установщик автоматически определяет рабочий стол и записывает в ярлык абсолютный
путь к текущему клону репозитория. Поэтому его нужно запустить повторно, если
репозиторий был перемещён или заново склонирован в другой каталог.

Перед запуском через ярлык приложение должно быть собрано командой
`umas-gui build`. Сам ярлык не запускает сборку автоматически.

Для `format` и `check` используется локальный `clang-format`, если он установлен.
Иначе CLI запускает инструмент в готовом Docker-образе. Если образ ещё не собран
или устарел, команда подскажет выполнить `umas-gui docker-build`.

Образ по умолчанию называется `umas-gui`, а `ROS_DOMAIN_ID` равен `1`. Значения можно
переопределить переменными `UMAS_GUI_IMAGE` и `ROS_DOMAIN_ID`.

Записи rosbag сохраняются в каталоге `bags` в корне репозитория UMAS GUI. Этот
каталог исключён из Git.

## Docker

Команда `umas-gui docker-build` собирает образ из `docker/Dockerfile`. Команды
`umas-gui build`, `umas-gui run` и `umas-gui shell` используют готовый образ и
не запускают его повторную сборку. Все параметры контейнера централизованы в CLI.

## Локальная сборка

Для локальной сборки необходимы ROS 2 Humble, Qt 5, SFML и GStreamer.

Через colcon:

```bash
colcon build --packages-select UMAS_GUI
source install/setup.bash
```

Через CMake:

```bash
cmake -S . -B build
cmake --build build -j
```

## ROS 2

По умолчанию контейнер запускается с `ROS_DOMAIN_ID=1`. Для другого домена передайте
переменную при запуске, например: `ROS_DOMAIN_ID=2 umas-gui run`.
