# Архив модулей

Здесь хранится код, который пока не подключён к актуальной версии UMAS GUI, но
может понадобиться при дальнейшей разработке.

Содержимое `legacy-ui` не входит в текущую сборку:

- `features/map` — виджеты и ресурсы карты;
- `features/modes` — прежняя реализация автоматического режима;
- `ui/panels` — панели `power_system`, `check_msg` и `check_imu`.

Перед возвращением модулей в `src` необходимо адаптировать их к текущим
интерфейсам, архитектуре и источникам данных `stingray_core`.
